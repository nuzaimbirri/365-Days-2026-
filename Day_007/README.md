# Day 007 - Cyber Core: Grid Defense 🛡️⚡

**Cyber Core: Grid Defense** adalah game strategi **Tower Defense Sci-Fi / Cyberpunk** futuristik dengan visual efek neon canvas, Web Audio API sound synthesizer buatan, sistem upgrade menara, super skill taktis, dan intelijen musuh multi-path.

## 🌟 Fitur Utama
1. **5 Varian Menara Defense Futuristik**:
   - 🔫 **Pulse Laser**: Tembakan laser berkecepatan tinggi pada target tunggal.
   - 💣 **Plasma Bomb**: Meriam ledakan area (AoE) untuk kerumunan musuh.
   - 🧊 **Cryo Beam**: Sinar es pembeku yang memperlambat musuh hingga 60%.
   - ⚡ **Tesla Coil**: Menembakkan petir yang merambat (*chain lightning*) ke 4 musuh sekaligus.
   - 🎯 **Railgun Sniper**: Jangkauan ekstrem & daya tembus tinggi melintasi armor & shield.

2. **5 Varian Virus / Enemy Malware**:
   - 🛸 **Cyber Drone**: Unit cepat ber-HP standar.
   - ⚡ **Speed Runner**: Sangat lincah dan cepat menembus pertahanan.
   - 🛡️ **Heavy Mech**: Tank bertubuh besar dengan HP tebal.
   - 👾 **Shielded Spectre**: Dilengkapi perisai energi penyerap damage.
   - 👹 **Titan Boss**: Bos raksasa dengan HP ribuan pada Wave 5, 10, 15, 20 & 25.

3. **Skill Taktis Operasional**:
   - 💥 **Orbital Laser Strike**: Panggil tembakan meriam laser dari satelit luar angkasa ke area pilihan.
   - ⚡ **EMP Pulse**: Lumpuhkan (*stun*) seluruh musuh di layar selama 4 detik.

4. **Sistem Inspeksi & Upgrade**:
   - Klik menara mana pun yang sudah terpasang untuk melihat statistik (*kills*, *damage*, *range*, *fire rate*).
   - Melakukan **Upgrade** untuk meningkatkan atribut menara atau **Menjualnya** untuk mengembalikan kredit.

5. **Audio Generator Synthesizer**:
   - Menggunakan **Web Audio API** bawaan tanpa bantuan file audio eksternal.

---

## 🎮 Cara Bermain
1. Buka `index.html` pada browser.
2. Pilih tipe menara dari panel kiri (atau tekan shortcut).
3. Klik pada grid area kosong untuk memasang menara pertahanan.
4. Klik tombol **MULAI GELOMBANG** untuk melepas pasukan musuh.
5. Pertahankan **Cyber Core** hingga Gelombang 25 Selesai!
